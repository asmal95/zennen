# Roadmap

## Фаза 0 — MVP (1–2 дня) ← ты здесь
- [x] Каркас бота на Go (go-telegram/bot, polling), voice-first + текст равноправен (Python-MVP в archive/)
- [x] Приём voice/audio/кружки + text → SQLite
- [x] STT: Whisper API (ключ обязателен)
- [x] Разбор по аспектам: только GPT через LLM API, без эвристик
- [x] Сущности regex: люди/проекты/места/даты/суммы/обещания
- [x] Команды: `/today /notes /week /tasks /ideas /delegations /search`
- [x] Напоминания: утро 9:00 (план), вечер 21:00 (рефлексия) + триггеры «напомни через…/в…/завтра» с ежеминутной отправкой
- [x] Делегирование-заглушка: DelegationCard + BaseAgentPlugin + `/delegations` (без исполнения)
- [ ] Подключить реальный токен и прогнать 3–5 голосовых
- [ ] Собрать первые 7 дней записей → проверить таксономию и сущности

## Фаза 1 — Личное пользование (приоритет; веб-вьювер НЕ делаем — см. ниже)
- [x] P0 Надёжность: systemd-юнит `diarybot` (Restart=always, enabled) + ежедневный бэкап `VACUUM INTO data/backups/` в 3:00 с ротацией 14 дней + `/export [ГГГГ-ММ]` → Markdown-файл (дневник невосстановим — сделано первым)
- [x] Weekly review текстом от LLM: планировал/сделал/темы/энергия (1 вызов в `/week`, plain text + чанкинг, `completed_at` для «сделано»)
- [x] `/person <имя>`, `/project <тег>` — вьюхи по связям (грубый стемминг падежей: Иван=Иваном, Маша=Маши; префикс вместо подстроки против «диван»; транслитерация пока не покрыта)
- [x] `/day [ГГГГ-ММ-ДД]` — просмотр любого дня (закрывает навигацию по истории без веб-вьювера)
- [x] UX-честность: молчаливых провалов нет (непонятное «напомни когда» — явный вопрос, а не тишина), неточные времена помечены как догадки, backdate чинится кнопкой «↩️ Это сегодня» (`MoveEntryDay`), STT низкой уверенности (`avg_logprob < -0.8`) спрашивает подтверждения вместо записи мусора, статусы утренней сверки правятся кнопками ✓/✗ (`pset`, `SetPlanStatusForce`)
- [x] Персональный часовой пояс: таблица `users`, спрос при `/start`, `/tz` + кнопки, ежеминутный диспетчер дайджестов по локальному часу (с catch-up после рестарта), все границы дней/парсинг времён по зоне пользователя
- [x] Планы на день: `target_date` у plan/task/fact-блоков (LLM + детерминированный оверрайд явных маркеров в Go — LLM систематически ошибался даже на «завтра»), таблица `plans`, `target_day` у задач; утро = напоминание планов сегодня + LLM-сверка вчера (done/missed) с отчётом; `/plans`, `/plandone`
- [x] Энергия 1–10: кнопки в вечернем дайджесте + `/energy [1–10]`, спарклайн в `/week`, ряд энергии в контексте weekly review (таблица `energy`, upsert по дню)
- [x] Кнопки под разбором: ✅ В задачу (без дублей) / ✏️ Исправить (замена текста + переразбор, день сохраняется) / 🗑 Удалить (с подтверждением; каскад: блоки/сущности/открытые задачи/несработавшие напоминания/proposed-делегации; выполненные задачи и история не трогаются) + `/delete_day [ГГГГ-ММ-ДД]`
- [ ] Группировка подтверждений (анти-спам при пачке голосовых)
- [ ] `re-analyze`: переразбор дня при смене промпта/модели
- [x] Запись задним числом: `entry_date` от LLM в том же вызове (вчера/позавчера/дни недели по таблице/явная дата); сроки задач («завтра сдать») на дату записи не влияют; будущее и старше года отсекает `ResolveEntryDate`
- [ ] Умные даты сверх покрытого: периоды («на неделе»), смешанные записи с событиями разных дней (сейчас — одна дата на запись)

## Фаза 2 — Память + групповые чаты (отдельный scope, после личного)
- [ ] Postgres + pgvector, embeddings (`/search` становится семантическим; триггер — 100+ записей или вьюхи не находят)
- [ ] Групповые чаты (scope `chat_id`, отдельно от личного): сырые сообщения → фильтр шума (regex, бесплатно) → часовые батчи в LLM → инкрементальное состояние чата (факты/планы/желания как diff) → дневной дайджест
- [ ] «Год назад» / итоги месяца
- [ ] TTS-дайджест голосом
- [ ] Фото/файлы: чек → трата, скрин → идея
- [ ] docker-compose: bot + db + (опц.) whisper-local

## Фаза 3 — Система (месяц+)
- [ ] Локальный режим приватности (faster-whisper + Ollama)
- [ ] Общий дневник / семейный бот
- [x] Веб-вьювер `WEB.md`: https://nen.zenai.space (Go stdlib + nginx + Let's Encrypt, magic link `/link` + `/revoke`, read-only v1, diary.db read-only + sessions.db отдельно, ревью с кэшем). Действия (v2) — отдельное решение
- [ ] Бэкапы + шифрование at rest

## Фаза 4 — Внешние агенты-исполнители (отдельный проект, здесь только интерфейс)
- Принцип: ядро не меняется. Новый репозиторий `ai-diary-agents/` реализует `BaseAgentPlugin`.
- [ ] `calendar-agent`: встречи из DelegationCard → Google Calendar
- [ ] `coder-agent`: задачи из дневника → GitHub issues / PR-черновики
- [ ] `travel-agent`: «найди билеты/отель» → отчёт обратно в чат дневника
- [ ] Подтверждение голосом: proposed → approved только после «да, поручи»
- [ ] Отчёт агента возвращается в ленту дня как `fact` с ссылкой на исходные заметки

## Критерии перехода между фазами
- MVP → Фаза 1: 7 дней подряд сам пользуешься, ≥2 записей/день.
- Фаза 1 → Фаза 2: есть 100+ записей, FTS-поиск уже не хватает.
- Фаза 2 → Фаза 3: хочешь отдать бота другим людям.
